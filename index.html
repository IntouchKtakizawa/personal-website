03 Personal project

JARVIS

My personal AI assistant experiment.

A browser interface backed by a local Node.js server, with model tool calling, saved conversations, notes and voice features. The public interface needs the local backend; model inference can use a connected cloud provider or Ollama.

JavaScript · Node.js · AI tool calling

04 Personal project

DebateAI

Exploring how AI can help develop an argument.

A debate workspace with timed speech drafts, round history and structured model responses. Built with Next.js and TypeScript, with Ollama and a local provider bridge. The public sample is prewritten; live AI needs a model connection.

Next.js · TypeScript · Zod · Ollama

Source ↗ Open project ↗
05 Personal project

Little World / AI Town

A sandbox for people, places and simulation rules.

A JavaScript and Canvas world with resident routines, needs, relationships and saved state, extended with city-building and map systems. Behavior runs locally using simulation rules; this version does not call a language model.

JavaScript · Canvas · simulation · local saves

Source ↗ Open project ↗
06 Personal project

Midpoint

Finding a meeting place that works for everyone.

A web project that explores fair meeting points using OpenStreetMap and OSRM travel-time routing. It grew out of the everyday problem of choosing somewhere convenient for a group.

Web development · OpenStreetMap · OSRM
